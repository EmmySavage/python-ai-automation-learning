Day 4 - Conditional Statements in Python

What you’ll learn

- Conditional statements allow programs to make decisions.
- if checks whether a condition is True.
- elif checks another condition when previous conditions are False.
- else executes when none of the previous conditions are True.
- Python uses indentation to define code blocks.

Practical application

Created a payment-status checker for a small business.

Concepts practiced

- Comparison operators
- Boolean values
- Conditional execution
- if, elif, and else
